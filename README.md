Surfing Dog AI provides an open-source, self‑hostable inbox that enables AI agents to interact with businesses through REST, MCP, and email. It tracks and lists agent‑ready businesses, offering searchable directories, trust networks, and integration capabilities for calendars, payments, and property systems. The platform powers a network where agents can discover, book, and communicate with businesses, while owners can manage items, rules, and AI‑driven workflows. Documentation, API reference, and quick‑start guides are publicly available, and the service runs on Cloudflare Workers and Node, exposing a public OpenAPI spec at https://inbox.surfingdog.ai/openapi.json.

**Areas:** Company · AI · Agent-Ready · Directory · Inbox
